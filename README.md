## The line

> The sock never moved, never thanked me, and smelled like a dare — so I ate it.

## How it works

`main.py` (stdlib only, deterministic) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads it back and verifies the kit gate: UTF-8 text, 1–200 characters, not only white space, a single line.

## Run

```sh
python3 main.py
```
